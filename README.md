# RFC's voor developer.overheid.nl

Voorstellen die meer dan één repository raken, moeilijk terug te draaien zijn,
of waarover anderen iets te zeggen hebben voordat ze vastliggen.

Hoe het werkt staat in [RFC-0000](text/0000-rfc-proces.md). Kort: kopieer
[`0000-template.md`](0000-template.md) naar `text/0000-korte-naam.md`, open een
pull request, en hernoem het bestand naar het nummer van die pull request.

## Overzicht

| RFC | Titel | Status | Geïmplementeerd |
| --- | --- | --- | --- |
| [0000](text/0000-rfc-proces.md) | Het RFC-proces | Draft | Deels |

## Reageren

Via een issue of rechtstreeks in de pull request van de RFC, bij de regel waar
je reactie over gaat. Eén alinea over één punt is genoeg; een reactie hoeft
geen volledige review te zijn.

Elke RFC noemt in zijn Behandeling-sectie tot wanneer er gereageerd kan worden.
Wie niet reageert, stemt nergens mee in.
